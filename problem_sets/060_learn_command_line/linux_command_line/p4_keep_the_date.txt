PROBLEM 4
Practises: finding an option in the manual, with man or --help.

Work on the course server. Log in with ssh and type these two commands first:
    # make the folder you work in; -p also makes the folders above it
    mkdir -p ~/problem_sets/060_learn_command_line/linux_command_line

    # go into it
    cd ~/problem_sets/060_learn_command_line/linux_command_line

The files to copy are in /opt/lectures/problem_sets/060_learn_command_line/linux_command_line/data/

Task: copy a file so that the copy keeps the original's date.
  1. cp gives a copy the time it was made. Find the option of cp that keeps the original's
     modification time: type man cp (q leaves it), or cp --help.
  2. Make a folder p4_keep_the_date, and with that option copy executions_MSFT.csv into it.

To check your work, type these two commands:
    cd ~/problem_sets/060_learn_command_line/linux_command_line
    ls -l p4_keep_the_date

They should print (your name will differ; the date and time must be the original's,
not the moment you copied it):
    total 4
    -rw-r--r-- 1 shahbaz shahbaz 1182 Oct 19 12:00 executions_MSFT.csv

NOTES
- To start this problem again, delete its folder with rm -r p4_keep_the_date (-r deletes a folder and
  everything in it, and there is no undo).

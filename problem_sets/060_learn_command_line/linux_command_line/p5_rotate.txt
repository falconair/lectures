PROBLEM 5
Practises: moving and renaming files with mv, which replaces a file without asking.

Work on the course server. Log in with ssh and type these two commands first:
    # make the folder you work in; -p also makes the folders above it
    mkdir -p ~/problem_sets/060_learn_command_line/linux_command_line

    # go into it
    cd ~/problem_sets/060_learn_command_line/linux_command_line

The files to copy are in /opt/lectures/problem_sets/060_learn_command_line/linux_command_line/data/

Task: a folder of daily prices, where today's prices are always called latest.csv.
  1. Make a folder p5_rotate, and a folder archive inside it.
  2. Copy ohlcv_2025-09-09.csv into archive as 2025-09-09.csv, ohlcv_2025-09-10.csv into p5_rotate
     as latest.csv, and ohlcv_2025-09-11.csv into p5_rotate as new_download.csv.
     This is the folder on the morning of the 11th, when that day's prices have just arrived.
  3. Using only mv: put the 10th's prices in archive as 2025-09-10.csv, and make new_download.csv
     the new latest.csv.

To check your work, type these two commands:
    cd ~/problem_sets/060_learn_command_line/linux_command_line
    ls -l p5_rotate p5_rotate/archive

They should print (your name and the times will differ; the sizes tell the three days apart):
    p5_rotate:
    total 8
    drwxrwxr-x 2 shahbaz shahbaz 4096 Oct 20 22:02 archive
    -rw-r--r-- 1 shahbaz shahbaz  595 Oct 20 22:02 latest.csv

    p5_rotate/archive:
    total 8
    -rw-r--r-- 1 shahbaz shahbaz 601 Oct 20 22:02 2025-09-09.csv
    -rw-r--r-- 1 shahbaz shahbaz 631 Oct 20 22:02 2025-09-10.csv

NOTES
- To start this problem again, delete its folder with rm -r p5_rotate (-r deletes a folder and
  everything in it, and there is no undo).

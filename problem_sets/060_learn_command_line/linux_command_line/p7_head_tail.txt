PROBLEM 7
Practises: head and tail, and saving what a command prints in a file with >.

Work on the course server. Log in with ssh and type these two commands first:
    # make the folder you work in; -p also makes the folders above it
    mkdir -p ~/problem_sets/060_learn_command_line/linux_command_line

    # go into it
    cd ~/problem_sets/060_learn_command_line/linux_command_line

The files to copy are in /opt/lectures/problem_sets/060_learn_command_line/linux_command_line/data/

Task: save the start and the end of a day's executions.
  1. Make a folder p7_head_tail.
  2. Save the header and the first five executions of executions.csv in p7_head_tail/first_five.csv,
     and the last five executions in p7_head_tail/last_five.csv. head -n and tail -n print n lines;
     > puts what a command prints into a file instead of on the screen.

To check your work, type these two commands:
    cd ~/problem_sets/060_learn_command_line/linux_command_line
    cat p7_head_tail/first_five.csv p7_head_tail/last_five.csv

PROBLEM 11
Practises: searching with grep, and counting lines with wc -l.

Work on the course server. Log in with ssh and type these two commands first:
    # make the folder you work in; -p also makes the folders above it
    mkdir -p ~/problem_sets/060_learn_command_line/linux_command_line

    # go into it
    cd ~/problem_sets/060_learn_command_line/linux_command_line

The files to copy are in /opt/lectures/problem_sets/060_learn_command_line/linux_command_line/data/

Task: count the buys among the executions.
  1. Make a folder p11_count_buys.
  2. The side column (the 5th) is 1 for a buy and 2 for a sell. Count the executions whose side is 1,
     and save the number in p11_count_buys/buys.txt.

To check your work, type these two commands:
    cd ~/problem_sets/060_learn_command_line/linux_command_line
    cat p11_count_buys/buys.txt

They should print (the number of buys):
    58

NOTES
- To start this problem again, delete its folder with rm -r p11_count_buys (-r deletes a folder and
  everything in it, and there is no undo).

PROBLEM 8
Practises: joining commands with | (cut, sort, uniq -c).

Work on the course server. Log in with ssh and type these two commands first:
    # make the folder you work in; -p also makes the folders above it
    mkdir -p ~/problem_sets/060_learn_command_line/linux_command_line

    # go into it
    cd ~/problem_sets/060_learn_command_line/linux_command_line

The files to copy are in /opt/lectures/problem_sets/060_learn_command_line/linux_command_line/data/

Task: count the executions of each symbol, the most traded symbol last.
  1. Make a folder p8_count_symbols.
  2. In one line of commands joined by |: take the symbol column of executions.csv (the 4th,
     cut -d, -f4), count how many times each symbol appears (uniq -c), and put the counts in
     order, smallest first (sort -n). Save the result in p8_count_symbols/counts.txt.
     If a symbol appears on more than one line of counts.txt, look again at what uniq does.

To check your work, type these two commands:
    cd ~/problem_sets/060_learn_command_line/linux_command_line
    tail -3 p8_count_symbols/counts.txt

They should print (the three most traded symbols, with how many executions each has):
          7 CUPR
         13 BIYA
         16 RMTI

NOTES
- To start this problem again, delete its folder with rm -r p8_count_symbols (-r deletes a folder and
  everything in it, and there is no undo).

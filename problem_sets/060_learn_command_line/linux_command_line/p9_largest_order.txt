PROBLEM 9
Practises: sorting numbers with sort -n.

Work on the course server. Log in with ssh and type these two commands first:
    # make the folder you work in; -p also makes the folders above it
    mkdir -p ~/problem_sets/060_learn_command_line/linux_command_line

    # go into it
    cd ~/problem_sets/060_learn_command_line/linux_command_line

The files to copy are in /opt/lectures/problem_sets/060_learn_command_line/linux_command_line/data/

Task: find the largest order quantity among the executions.
  1. Make a folder p9_largest_order.
  2. In one line of commands joined by |: take the order_qty column of executions.csv (the 6th),
     sort it, and keep the last line. Save it in p9_largest_order/largest.txt.
     If the answer is smaller than an order you can see in the file, look at how sort compares.

To check your work, type these two commands:
    cd ~/problem_sets/060_learn_command_line/linux_command_line
    cat p9_largest_order/largest.txt

They should print (the largest order quantity):
    2000

NOTES
- To start this problem again, delete its folder with rm -r p9_largest_order (-r deletes a folder and
  everything in it, and there is no undo).

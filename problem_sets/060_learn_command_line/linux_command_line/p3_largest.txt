PROBLEM 3
Practises: reading the sizes that ls -l shows.

Work on the course server. Log in with ssh and type these two commands first:
    # make the folder you work in; -p also makes the folders above it
    mkdir -p ~/problem_sets/060_learn_command_line/linux_command_line

    # go into it
    cd ~/problem_sets/060_learn_command_line/linux_command_line

The files to copy are in /opt/lectures/problem_sets/060_learn_command_line/linux_command_line/data/

Task: find the largest price file.
  1. Look at the data folder with ls -l. The fifth column is each file's size in bytes.
  2. Make a folder p3_largest, and copy the largest of the three files ohlcv_2025-09-09.csv,
     ohlcv_2025-09-10.csv and ohlcv_2025-09-11.csv into it as largest.csv.

To check your work, type these two commands:
    cd ~/problem_sets/060_learn_command_line/linux_command_line
    ls -l p3_largest

They should print (your name and the time will differ):
    total 4
    -rw-r--r-- 1 shahbaz shahbaz 631 Oct 20 22:02 largest.csv

NOTES
- To start this problem again, delete its folder with rm -r p3_largest (-r deletes a folder and
  everything in it, and there is no undo).

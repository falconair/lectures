# problem_sets/

Problem sets, one folder per lecture. The path mirrors the lecture's:

```
lectures/110_python_py_files/100-program-inputs.ipynb      the lecture
problem_sets/110_python_py_files/100-program-inputs/       its problem set
```

Each folder holds a few small programs and the data file they read. The comment at the top of each program says what to do and how to check your work. Your Canvas assignment says which ones are due.

If a lecture is renamed or moved, rename or move its problem set the same way, then check:

```bash
# from anywhere in this repository
# lists every problem set that no longer matches a lecture
python problem_sets/check_names.py
```

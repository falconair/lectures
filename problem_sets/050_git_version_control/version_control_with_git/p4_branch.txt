PROBLEM 4
Practises: making a branch, committing on it, and merging it into main with a merge commit.

Work on the course server: log in with ssh, then do the steps below there.

Task: raise the minimum commission on a branch, and bring it into main once it works.
  1. Copy the project and make it a repository with one commit: type these commands.
         # make the folder you work in; -p also makes the folders above it
         mkdir -p ~/problem_sets/050_git_version_control/version_control_with_git

         # go into it
         cd ~/problem_sets/050_git_version_control/version_control_with_git

         # copy the folder starter as p4_branch; -r (recursive) copies everything inside it, folders and all
         cp -r /opt/lectures/problem_sets/050_git_version_control/version_control_with_git/starter p4_branch

         # go into p4_branch
         cd p4_branch

         # make this folder a repository: git keeps the history in a hidden folder, .git
         git init

         # put every file on the stage (. means this folder)
         git add .

         # save what is on the stage in the history, with a message (-m)
         git commit -m "Starting point"

  2. Make a branch called higher-minimum and switch to it. With nano, change MINIMUM_COMMISSION = 1.00
     to MINIMUM_COMMISSION = 2.00, and commit that on the branch.
  3. Switch back to main and merge the branch with a merge commit, typed as
     git merge --no-ff --no-edit higher-minimum (--no-edit keeps the message git suggests).
     Then delete the branch.

To check your work, type these three commands:
    cd ~/problem_sets/050_git_version_control/version_control_with_git/p4_branch
    git log --oneline --graph --all
    git branch

They should print (your hashes will differ, and the messages of your first two commits are your own):
    *   318ad8f (HEAD -> main) Merge branch 'higher-minimum'
    |\  
    | * d77f110 Raise the minimum commission to 2.00
    |/  
    * fe12766 Starting point
    * main

NOTES
- Before your first commit on the server, tell git who you are: type the three git config commands
  from section 1 of the lecture (user.name, user.email and init.defaultBranch main). If you made the
  repository before that, git calls the main line master instead of main. That is fine.
- nano FILE opens a file to edit: ctrl+O then enter saves it, ctrl+X leaves.
- To start this problem again, delete its folder with rm -rf p4_branch (-rf also deletes the .git
  folder inside it, and there is no undo).

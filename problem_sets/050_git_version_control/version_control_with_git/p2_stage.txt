PROBLEM 2
Practises: the three places a change can be: the working folder, the stage (git add) and
the history (git commit).

Work on the course server: log in with ssh, then do the steps below there.

Task: leave one change in each of the three places.
  1. Copy the project and make it a repository with one commit: type these commands.
         # make the folder you work in; -p also makes the folders above it
         mkdir -p ~/problem_sets/050_git_version_control/version_control_with_git

         # go into it
         cd ~/problem_sets/050_git_version_control/version_control_with_git

         # copy the folder starter as p2_stage; -r (recursive) copies everything inside it, folders and all
         cp -r /opt/lectures/problem_sets/050_git_version_control/version_control_with_git/starter p2_stage

         # go into p2_stage
         cd p2_stage

         # make this folder a repository: git keeps the history in a hidden folder, .git
         git init

         # put every file on the stage (. means this folder)
         git add .

         # save what is on the stage in the history, with a message (-m)
         git commit -m "Starting point"

  2. With nano, make the last line of commission.py print Total commission for the day: instead of
     Total commission:. Add it and commit it.
  3. With nano, add a trade at the end of trades.csv: 13:05:52,AAPL,1500,226.95. Add it (git add),
     but do not commit it.
  4. With nano, change MINIMUM_COMMISSION = 1.00 to MINIMUM_COMMISSION = 2.00 in commission.py.
     Do not add it.

To check your work, type these three commands:
    cd ~/problem_sets/050_git_version_control/version_control_with_git/p2_stage
    git status
    git log --oneline

They should print (your hashes will differ, and the messages are your own):
    On branch main
    Changes to be committed:
      (use "git restore --staged <file>..." to unstage)
    	modified:   trades.csv

    Changes not staged for commit:
      (use "git add <file>..." to update what will be committed)
      (use "git restore <file>..." to discard changes in working directory)
    	modified:   commission.py

    d2a0dc6 (HEAD -> main) Say that the total is for the day
    fe12766 Starting point

NOTES
- Before your first commit on the server, tell git who you are: type the three git config commands
  from section 1 of the lecture (user.name, user.email and init.defaultBranch main). If you made the
  repository before that, git calls the main line master instead of main. That is fine.
- nano FILE opens a file to edit: ctrl+O then enter saves it, ctrl+X leaves.
- To start this problem again, delete its folder with rm -rf p2_stage (-rf also deletes the .git
  folder inside it, and there is no undo).
